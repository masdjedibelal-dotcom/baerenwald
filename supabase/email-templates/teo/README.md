# Supabase Auth — E-Mail-Vorlagen (MeinTEO)

Wie die Bärenwald-Vorlagen eine Ebene höher, im TEO-Design (Blau `#1e5fa8`, Dunkel `#0b1f3a`, Hinweis-Box `#dce4ee`, Logo `https://servus-teo.de/brand/teo/mail-logo-green.png`), Anrede „Sie“.

Eingetragen im TEO-Prod-Projekt (Authentication → Emails):

| Vorlage in Supabase  | Datei                 | Betreff                                |
|----------------------|-----------------------|----------------------------------------|
| Confirm signup       | `confirm-signup.html` | MeinTEO — E-Mail bestätigen            |
| Invite user          | `invite.html`         | MeinTEO — Ihre Einladung               |
| Magic link           | `magic-link.html`     | MeinTEO — Ihr Anmelde-Link             |
| Change email address | `change-email.html`   | MeinTEO — Neue E-Mail bestätigen       |
| Reset password       | `reset-password.html` | MeinTEO — Passwort zurücksetzen        |
